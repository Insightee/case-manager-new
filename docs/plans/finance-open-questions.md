# Finance — open questions register

plan: [docs/plans/finance-dashboard-revamp.md](./finance-dashboard-revamp.md)

Escalation register for the finance grind loops. **A financial rule that is not in code and not in the initiative is an open question, never an inference.**

## Protocol

On escalation the loop must, in this order:

1. Append a row to Open questions below.
2. Set the work package to `Blocked` on the plan board.
3. Stop and report.

The loop **may not resume that package** until the question has a non-empty `Answer` and `Answered by`. Moving a row to Answered is a human action. An agent may not answer its own escalation, soften the question, or proceed on a "reasonable default".

## Escalation triggers

A migration is newly required · an API contract must change unexpectedly · a financial rule is ambiguous or absent · role access is unclear · an existing test contradicts the approved requirement · Railway or Vercel configuration would need modifying · the work cannot be done inside the permitted scope.

Never infer a rate, proration basis, rounding mode, status transition, eligibility rule or leave entitlement.
